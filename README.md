# WorkBuddy 任务助手

一个纯 Python 的 WorkBuddy 任务批量执行工具。双击运行、无需安装第三方依赖、中文界面。

这是我用 AI 将 [Sliverkiss/workbuddy2api](https://github.com/Sliverkiss/workbuddy2api) 项目里"自动做成长任务"部分功能拆出来、做成的独立脚本。
原项目是完整的 Go 网关，需要 Go、Docker 环境才能运行；该脚本只保留了自动完成任务相关的功能。脚本的合并、显示和交互按我自己的想法做了调整，操作更便捷，适合没有 API 服务或网关功能需求、也不想部署运行环境，只需要批量完成任务积分的用户（详见文末"来源与许可"）。

这个仓库用来自己做备份。

## 功能

- 启动后列出全部已登录账号，可以单独操作指定账号，也可以对所有账号批量执行
- 完成成长任务、小程序限定任务、开学季活动任务，三类任务合并处理
- 每日签到、猫猫旅行（派出/领奖）、开学季小程序抽奖、活跃地图（连登兑换/抽奖）等每日功能
- 将原脚本的英文运行日志转成中文，任务状态一目了然
- 支持登录新账号：按 `n` 会打开授权网页并自动轮询检测，最长等待 5 分钟

## 运行环境

- 仅支持 macOS。入口为 `.command` 文件
- Python 3.10 及以上。脚本会自动去常见安装位置查找，不用管 `python3` 指向哪个版本。未安装的话二选一：已装 Homebrew 执行 `brew install python@3.13`；否则安装 uv（`curl -LsSf https://astral.sh/uv/install.sh | sh`，重开终端后执行 `uv python install 3.13`）
- 仅使用 Python 标准库，无需 pip 安装任何依赖

## 使用方法

1. 下载整个文件夹。
2. 首次使用先给入口脚本添加执行权限：

   ```bash
   chmod +x WorkBuddy任务助手.command
   ```

3. 双击 `WorkBuddy任务助手.command`
4. 在第一屏按 `n` 登录账号，页面会打开授权网页，授权后脚本自动检测
5. 回到第一屏，输入账号前的数字进入该账号的任务清单，或按 `j` / `k` 一次性跑完所有账号

首次登录成功后会自动生成 `auths/` 目录，里面是登录凭证，请勿外传。

## 按键说明

第一屏（账号列表）：

| 按键 | 作用 |
|---|---|
| `1` … `9` | 进入对应账号的任务清单 |
| `n` | 登录新账号 |
| `j` | 所有账号 · 全量完成任务 |
| `k` | 所有账号 · 全量完成每日任务 |
| `r` | 重新扫描 `auths/` 目录 |
| `q` | 退出 |

任务清单屏：

| 输入 | 作用 |
|---|---|
| `a` `b` `c` `d` | 执行整组（每日 / 限时 / 已完成待领 / 不限时，字母按显示位置分配） |
| 数字 | 执行指定任务，支持 `1 3 5`、`1,3,5`、`1、3、5` |
| 范围 | `4-8`，或字母范围 `a-b` |
| 混合 | `a 5` |
| `0` | 执行全部可执行任务 |
| `t` | 换账号 |
| `q` | 退出 |

输入即执行，无需二次确认；重复执行是幂等的，已完成的任务会自动跳过。

## 风险说明

- 本工具通过直接调用接口的方式绕过官方客户端来执行任务。
- 这可能违反相关服务条款，存在账号被限制或积分被清零的风险，请自行判断并承担后果。
- 上游项目在其说明中同样写明了这一点，本项目只是沿用。
- 本项目与 WorkBuddy、腾讯官方没有任何关联，属于非官方工具。
- `auths/` 中存放的是明文登录凭证，等同于账号的钥匙，切勿提交到公开仓库或发给他人。本项目的 `.gitignore` 已默认排除该目录，仍建议自行确认一次。

## 来源与许可

工具的核心代码来自 [Sliverkiss/workbuddy2api](https://github.com/Sliverkiss/workbuddy2api)（MIT 协议），版权归原作者所有。我用 AI 将其中"自动做成长任务"的部分单独拆出来，做成可以双击运行的独立脚本，并在功能和交互上按自己的想法做了调整：

- 整合为统一入口，界面更友好、交互更便捷，如启动后直接展示账号列表，输入数字选择对应账号、输入编号选择对应任务
- 重新规划了任务清单的显示逻辑，包括分组顺序、对齐方式等
- 将执行结果整理为中文清单，细分任务状态，如把"已完成""之前已领""完成但领奖失败""需手动操作"等情形分开显示
